# Session 20 - Initiative Tracker Encounters

Use these blocks as plug-and-play starts. Budgets assume **Level 2** PCs and Daggerheart Battle Points: base `[(3 × PCs) + 2]`, then `+2` for a harder/longer fight, `+1` when the package includes lower-tier adversaries.

Parallel lanes share one Fear pool, which softens each front slightly — spend Fear on position and clocks, not triple-spotlighting one lane.

---

## Difficulty Snapshot

| Lane | Focus PCs | Target BP | Built BP | Verdict |

| A Pens | Fianna (1; reinforce if rotated) | 5–7 (8 if 2 PCs) | 6 base / 8 reinforced | Challenging escort; do not open with two supports |

## Encounter A - Pens Breakout (Fianna lane)

```encounter
name: Session 20 - Pens Breakout
creatures:
  - Dire Pangolati
  - Bladed Guard
```

**BP:** Pangolati 4 + Bladed Guard 2 = **6** (1 PC budget ~5–7).

Notes:
- Open with Pangolati + **one** Circle warden (Bladed Guard, reflavored). Escort pressure is the second threat.
- If a second PC rotates in, add **Conscript ×2** (Tier 2 Minion group = 1 BP) → **7**, or a second Bladed Guard → **8**.
- Do **not** default Shadeveil Hunter here; Armor Eater + Blade Fling already punish a solo protector hard.
- Pangolati prioritizes hostage-lane disruption over focus-firing Fianna.

## Encounter B - Living Rite Diversion (Sabriel + Gnirth lane)

```encounter
name: Session 20 - Living Rite Diversion
creatures:
  - Fowlbear
  - Doppelhound
  - Cult Initiate
  - Cult Initiate
```

**BP:** Fowlbear 4 + Doppelhound 2 + Cult Initiate group (2 minions for 2 PCs) 1 = **7** (2 PC budget ~8–10). Add [[The Masked Commander]] (+3 Leader) when she fully enters → **10**.

Notes:
- Run Doppelhound duplicate immediately.
- Fowlbear guards Tavore and the anchors; Dread Honk breaks beat-window positioning.
- Cult Initiates are rite attendants — body-block anchors and soak one spotlight, not a third elite.
- Keep Tavore on **command pressure** early (Commander's Presence, Hold the Beat). Bring her sheet in when PCs engage her or need a rite spike.
- If the lane feels soft after a clean first exchange, add Tavore or **one Bladed Guard** (+2 → **9**).
- If overloaded (Stress stacking, Ritual Hunger already at 3), drop both Initiates and keep Fowlbear + Doppelhound only (**6**).

## Encounter C - Elder Platforms (Fern + Snicket lane)

```encounter
name: Session 20 - Elder Platforms
creatures:
  - Leshen Warden
  - Tangle Bramble
  - Tangle Bramble
```

**BP:** Leshen Solo 5 + Tangle Bramble group (2 minions for 2 PCs) 1 = **6** (2 PC budget ~8–10; Solo Relentless + Diff 16 with Pinned Host closes the gap).

Notes:
- Leshen is the only elite. Two Brambles create rescue friction and can fuse into a Swarm if ignored.
- Drop both Brambles if mercy path is clearly succeeding and you want a clean Sever the Brand climax.
- If kill branch and the fight stalls soft, add **two more Tangle Brambles** (still one minion spend if treated as the same group size refresh) or convert surviving Brambles into a **Tangle Bramble Swarm** via Drain and Multiply.
- Spend Fear on Root Binding and platform collapse, not a second elite.

Notes:

- Fresh full-party budget would be ~17; this scene should feel like a climax spike, not a new equal fight.

## Quick Scaling Dials

- **Too easy:** Add one Standard/support, or one Minion group equal to PCs in that lane.
- **Too hard:** Remove the softest support/minions first; never strip the lane's fantasy boss on the first dial.
- **Too slow:** Convert one hostile into pure objective pressure (hostage grab, anchor lash, bridge threat) instead of full combatant.
- **PC rotates into a lane:** Immediately spend +2–3 BP of supports/minions, not another Bruiser/Solo.
